1. 시스템 개요

목적
보성군 지역 농가·소상공인(보흥제유소, 다향농장, 주방철물 등)의 상품을 자사몰(BMCTVda)에 등록·판매하고, 동일한 상품 데이터를 쿠팡, 쿠팡 파트너스, 토스쇼핑 등 외부 채널에도 위탁판매 형태로 연결하는 통합 커머스 플랫폼을 구축한다. 지역화폐 기반 통합돌봄 주문관리 시스템과는 별개의 프로젝트이며, 대상 고객층(일반 소비자, 전국 단위)과 판매 구조(위탁판매 계약 기반 다채널 유통)가 다르다.

핵심 설계 원칙
- 자사몰이 상품 데이터의 단일 원천(Single Source of Truth) 역할을 한다. 공급처가 상품을 한 번 등록하면 그 정보가 자사몰 판매와 외부 채널 연동에 동시에 쓰인다.
- 자사몰 자체가 일반 소비자 대상 쇼핑몰 기능(상품 조회·주문·결제)을 갖춘다.
- 동시에 등록된 상품 정보(사진, 설명, 가격, 사업자 정보)를 쿠팡·쿠팡파트너스·토스쇼핑 등 외부 판매채널에 수동 또는 반자동으로 연동할 수 있는 구조를 둔다.
- 위탁판매 계약 조건(수수료율, 정산 주기, 배송 방식)이 공급처마다 다르므로, 공급처 단위로 계약 조건을 데이터로 관리한다.

2. 사용자 유형 및 화면 구성

2-1. 공급처(농가·소상공인) 화면 — 상품 등록
- 공급처 로그인 (계약 체결된 공급처만 접근)
- 상품 등록 폼: 상품명, 카테고리, 상품 사진(다중 업로드), 규격·중량, 공급가, 권장판매가, 원산지, 소비기한, 표시사항(식품인 경우 원재료명·보관방법 등), 재고 수량
- 사업자 정보: 상호, 대표자, 사업자등록번호, 사업장 주소, 연락처 (계약서 기준 자동 불러오기)
- 등록 상품 목록 및 상태 확인 (승인대기/판매중/품절/판매중지)
- 판매 현황 조회: 본인 상품의 주문 건수, 판매금액, 정산 예정액

2-2. 관리자 화면(히스메이커스) — 통합 관리
- 상품 승인: 공급처가 등록한 상품을 검수 후 승인·반려 (표시사항 누락, 사진 품질 등 확인)
- 상품 통합 관리: 전체 공급처의 상품을 한 화면에서 조회·수정, 카테고리별·공급처별 필터
- 채널 연동 관리: 승인된 상품 중 어떤 채널(자사몰/쿠팡/쿠팡파트너스/토스쇼핑)에 노출할지 선택. 채널별 판매가 조정(수수료·배송비 반영), 채널별 상품 상세 문구 커스터마이징
- 위탁판매 계약 조건 관리: 공급처별 판매수수료율, 정산 주기(익월 15일 등), 배송 방식(위탁배송 원칙), 할인 허용 한도(권장판매가 대비 20% 등) 등록·조회
- 주문 통합 관리: 자사몰 직접 주문과 외부 채널 주문(연동 가능한 채널은 API로, 그 외는 수동 입력)을 하나의 목록에서 확인, 공급처에 주문 정보 전달(영업일 1일 이내 원칙)
- 정산: 채널별·공급처별 판매금액, 수수료 공제, 반품·환불 반영한 정산 내역 생성 및 공급처별 정산서 출력
- 캠페인에 연동 참고 자료 연결: 브랜드커넥트 캠페인 등 홍보 콘텐츠와 상품 데이터를 연결해 캠페인 페이지에서 바로 구매로 이어지는 랜딩 구조 (2단계 고려)

2-3. 소비자 화면 — 자사몰 쇼핑
- 상품 목록·검색·카테고리 탐색 (농산물, 가공식품, 생활철물 등)
- 상품 상세 페이지: 사진, 설명, 원산지, 가격, 공급처(생산자) 소개
- 장바구니, 주문, 결제(자사몰 자체 결제 연동 필요 — PG사 선정 별도 검토)
- 주문 조회, 배송 조회

3. 데이터 모델 (핵심 테이블)

공급처(Supplier)
- 공급처ID, 상호, 대표자명, 사업자등록번호, 사업장주소, 연락처, 계약체결일, 계약상태

위탁판매계약조건(SupplierContract)
- 계약ID, 공급처ID, 판매수수료율, 정산주기, 배송방식, 할인허용한도(%), 계약기간, 비고

상품(Product)
- 상품ID, 공급처ID, 상품명, 카테고리, 규격, 공급가, 권장판매가, 원산지, 소비기한, 재고수량, 승인상태(대기/승인/반려), 등록일

상품이미지(ProductImage)
- 이미지ID, 상품ID, 이미지URL, 순서

채널연동(ChannelListing)
- 연동ID, 상품ID, 채널구분(자사몰/쿠팡/쿠팡파트너스/토스쇼핑), 채널노출상태(노출/미노출), 채널별판매가, 채널별상품URL(연동 완료 시)

주문(Order)
- 주문ID, 채널구분, 소비자정보(이름/연락처/배송지), 주문일시, 상태(주문접수/공급처전달/출고/배송중/완료/반품), 합계금액

주문항목(OrderItem)
- 주묹항목ID, 주문ID, 상품ID, 수량, 판매단가, 소계

정산(Settlement)
- 정산ID, 공급처ID, 정산기간, 판매금액합계, 수수료공제액, 반품환불액, 지급액, 정산일, 지급상태

-----

4. 외부 채널 연동 방식

자사몰(BMCTVda)
- 직접 운영, 상품·주문·결제 전 과정을 자체 시스템에서 처리

쿠팡
- 쿠팡 오픈API를 통한 상품 등록·주문 수집 연동 (2단계 목표, 1단계는 수동 등록)

쿠팡파트너스
- 제휴 링크 발급 방식, 자사몰 상품 페이지에 파트너스 링크 삽입 또는 별도 프로모션 페이지 운영

토스쇼핑 및 기타 링크형 채널
- 상품 정보를 표준 형식(상품명/사진/가격/링크)으로 내보내는 연동, 초기에는 수동 등록, 추후 API 지원 여부에 따라 자동화 검토

-----

5. 단계별 구축 로드맵

1단계 (클로드 코드로 우선 구축)
- 공급처 상품 등록 화면 + 관리자 승인·통합관리 화면
- 자사몰 소비자 쇼핑 화면 (상품조회~주문접수, 결제는 우선 계제이체 안내 등 간이 방식으로 시작 가능)
- 채널연동 테이블 구조는 만들되, 실제 API 연동 없이 관리자가 수동으로 외부 채널 등록 여부만 표시·관리
- 위탁판매 계약 조건 데이터 관리 (보흥제유소·다향농장·주방철물 계약 내용 반영)

2단계 (추후 확장)
- 쿠팡 오픈API 연동으로 상품 등록·주문 수집 자동화
- 자사몰 실 결제(PG) 연동
- 정산 자동화 및 공급처별 정산서 자동 발송

3단계 (장기)
- 쿠팡파트너스·토스쇼핑 등 다채널 자동 연동 확대
- 브랜드커넥트 캠페인 콘텐츠와 상품 페이지 연결한 인플루언서 마케팅 랜딩 구조
- 판매 데이터 기반 공급처별 추천 상품·시즌 기획전 자동 제안

-----

6. 미결정 사항 (클로드 코드 착수 전 확인 필요)
- 자사몰 결제수단(PG사) 선정 여부 및 시점 (1단계는 간이 결제 방식으로 시작할지 여부)
- 호스팅 서비스 및 도메인(BMCTVda 자사몰 도메인 연결 여부)
- 공급처 로그인 인증 방식 (계약 공급처마다 별도 계정 발급 여부)
- 쿠팡 오픈API 신청 및 승인 절차 (사업자 요건 확인 필요)
- 지역화폐 기반 통합돌봄 시스템과 회원 데이터·상품 데이터를 공유할지 완전히 분리된 별도 시스템으로 둘지 여부 (예: 생활장터 장보기 품목과 자사몰 상품이 같은 상품 데이터베이스를 쓸 수 있는지 추후 검토)
