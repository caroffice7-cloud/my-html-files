# 서버에 올리기 전에, 내 PC에서 먼저 보기

배포하기 전에 대표님 컴퓨터에서 먼저 돌려 보고 검토하실 수 있습니다.
**인터넷에 공개되지 않고 대표님 PC 안에서만 열립니다.**

---

## 먼저 알아 두실 것 — HTML 파일만으로는 안 됩니다

이 프로그램은 단순한 웹페이지가 아니라 **서버가 함께 돌아가는 프로그램**입니다.

```
화면(HTML)  ──"메뉴 목록 주세요"──▶  서버  ──▶  데이터베이스
                                  (계산·저장)
```

잔액 계산, 월 한도 차단, 정산, 회원 관리가 전부 서버 쪽에 있습니다.
그래서 `index.html` 파일을 더블클릭해서 열면 **틀만 보이고 내용은 비어 있습니다.**

대신 아래 방법으로 **서버까지 대표님 PC에서 함께 돌리면** 실제와 똑같이 보실 수 있습니다.

---

## 1단계 — Node.js 설치 (한 번만)

1. https://nodejs.org 접속
2. 왼쪽의 **LTS** 버튼 클릭해서 내려받기
3. 내려받은 파일 실행 → 계속 "다음"만 누르면 설치 완료

> 이미 설치되어 있다면 건너뛰세요. 확인하려면 명령 프롬프트에서 `node -v` 를 입력했을 때
> `v22.` 이상이 나오면 됩니다.

---

## 2단계 — 코드 내려받기

### 가장 쉬운 방법 (ZIP 파일)

1. 아래 주소를 브라우저에 붙여넣습니다.
   ```
   https://github.com/caroffice7-cloud/my-html-files/archive/refs/heads/claude/local-currency-market-system-g6jdss.zip
   ```
2. 내려받은 ZIP 파일을 **압축 해제**합니다. (예: 바탕화면에 풀기)
3. 풀린 폴더 안에 `server.js`, `시작하기-윈도우.bat` 같은 파일이 보이면 됩니다.

### 익숙하시다면 (Git)

```bash
git clone -b claude/local-currency-market-system-g6jdss https://github.com/caroffice7-cloud/my-html-files.git
```

---

## 3단계 — 실행

폴더 안의 파일을 **더블클릭**하면 됩니다.

| 운영체제 | 실행할 파일 |
| --- | --- |
| 윈도우 | `시작하기-윈도우.bat` |
| 맥 | `시작하기-맥용.command` |

검은 창이 뜨고, 3초 뒤 브라우저가 자동으로 열립니다.

> **맥에서 "확인되지 않은 개발자" 경고가 뜨면** — 파일을 마우스 오른쪽 클릭 →
> "열기" → 다시 "열기"를 누르면 실행됩니다.

### 열리는 화면

| 화면 | 주소 | 로그인 |
| --- | --- | --- |
| 소비자 쇼핑몰 | http://localhost:3000/ | 로그인 없음 |
| 공급처 화면 (농가·소상공인) | http://localhost:3000/supplier | `bohueng` / `bohueng2026` (보흥제유소)<br>`dahyang` / `dahyang2026` (다향농장)<br>`jubang` / `jubang2026` (주방철물) |
| 운영자 화면 | http://localhost:3000/admin | 아이디 `admin` / 비밀번호 `bmctvda2026` |

**끄실 때는 검은 창을 닫으면 됩니다.**

## 검토하실 때 눌러 보시면 좋은 것

처음 실행하면 **판매 중인 상품이 하나도 없습니다.** 공급처가 가격을 넣고 운영자가 승인해야
쇼핑몰에 나타나기 때문입니다. 아래 순서대로 해 보시면 전체 흐름이 한 번에 보입니다.

### ① 공급처 입장 — http://localhost:3000/supplier
- [ ] `bohueng` / `bohueng2026` 으로 로그인
- [ ] "내 상품" 에 계약서 별지의 품목(참기름·들기름 등)이 들어 있는지 확인
- [ ] "계약 · 내 정보" 에서 **내 수수료율 25%, 정산 익월 15일** 이 맞게 보이는지 확인
- [ ] 참기름 "수정" → 공급가·권장판매가·재고 입력 → 저장 → "승인요청"
- [ ] 사진을 한 장 올려 보기 (휴대폰 사진도 됩니다 — 자동으로 줄여서 올라갑니다)

### ② 운영자 입장 — http://localhost:3000/admin
- [ ] `admin` / `bmctvda2026` 으로 로그인
- [ ] 대시보드에 "승인 대기 상품" 이 뜨는지
- [ ] "상품 승인 · 관리" 에서 방금 그 상품 **승인**
- [ ] **수수료 관리** 화면 열어 보기 — 공급처별 기본율과 상품별 개별율,
      건당 수수료와 농가 정산액이 함께 보입니다. 농가에 보여드리며 설명하실 화면입니다.
- [ ] 주방철물의 기본 수수료율에 숫자를 넣어 보고 저장 → 변경 이력에 남는지 확인
- [ ] "공급처 · 계약" 에서 새 공급처를 하나 추가해 보기 (상태를 "협의중" 으로)

### ③ 소비자 입장 — http://localhost:3000/
- [ ] 승인한 상품이 목록에 나타나는지
- [ ] 상품을 눌러 상세 화면(사진·원산지·소비기한·생산자 소개) 확인
- [ ] 장바구니 → 주문 → 주문번호 받기
- [ ] "주문조회" 에서 주문번호 + 연락처로 조회
- [ ] 휴대폰으로도 열어 보기 → 같은 와이파이라면 PC의 IP 주소로 접속 가능
      (명령 프롬프트에 `ipconfig` 입력 → IPv4 주소 확인 → 휴대폰에서 `http://그주소:3000`)

### ④ 다시 운영자 — 주문부터 정산까지
- [ ] "주문 관리" 에서 방금 주문 확인 → 입금 확인 체크 → 상태를 "공급처전달" 로
- [ ] 공급처 화면 "주문 · 발송" 에서 송장번호 입력 → 주문이 자동으로 "출고" 가 되는지
- [ ] "정산" 화면에서 공급처별 판매금액·수수료·지급대상 확인 → **정산서 생성**
- [ ] 정산서 CSV 를 내려받아 엑셀로 열어 보기
- [ ] "운영자 계정" 에서 담당자 계정을 하나 만들고, 그 계정으로 로그인했을 때
      공급처·수수료·정산 지급 메뉴가 숨겨지는지 확인

## 자주 겪는 문제

| 증상 | 해결 |
| --- | --- |
| 검은 창이 바로 닫힘 | Node.js가 설치되지 않았습니다. 1단계를 다시 하세요. |
| "포트가 이미 사용 중" | 다른 프로그램이 3000번을 쓰고 있습니다. 창을 닫고 잠시 뒤 다시 실행하세요. |
| 브라우저에 아무것도 안 뜸 | 검은 창이 켜져 있는지 확인하세요. 꺼져 있으면 서버도 꺼진 것입니다. |
| 화면은 뜨는데 내용이 빔 | `index.html` 을 직접 연 경우입니다. 반드시 `시작하기` 파일로 실행하세요. |
| 쇼핑몰에 상품이 없음 | 정상입니다. 공급처가 가격을 넣고 운영자가 승인해야 나타납니다. 위 ①②번을 해 보세요. |
| 처음부터 다시 보고 싶음 | `data` 폴더의 `mall.db` 파일과 `public/uploads` 안의 사진을 지우고 다시 실행하면 초기 상태가 됩니다. |

## 검토가 끝나면

내 PC에서 만든 데이터(`data/mall.db`, 올린 사진)는 **서버로 옮기지 않습니다.** 검토용이므로
실제 운영은 서버에서 깨끗한 상태로 새로 시작합니다.

서버 배포는 [DEPLOY.md](DEPLOY.md) 를 보시거나, 서버가 준비되면 함께 진행하겠습니다.
